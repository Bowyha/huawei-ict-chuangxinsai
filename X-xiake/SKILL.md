# 景点出片教练 Skill

> v1.4.0｜先问清需求，再为每个方案生成“真实景点背景 + 高对比火柴人 + 真人参考图 + 沟通话术 + 摄影执行卡”。

## 触发

用户说“[地点]怎么拍”“帮我规划[景点]拍照”“一个人/一家人/团建怎么拍”时触发。不得在未收集关键条件前直接生成方案。

## 交互式收集（第一轮只问 4 个问题）

1. **几个人拍？** 单人 / 情侣或双人 / 家庭 / 朋友 / 公司团建；儿童、老人分别几位？
2. **想要哪种感觉？** 自然抓拍 / 氛围感 / 大气全身 / 轻松日常；是否介意露脸？
3. **谁来拍、用什么设备？** 他拍或自拍；手机型号/普通手机；是否有三脚架或遥控器？
4. **现场条件？** 是否已有该景点实拍图；预计白天/日落/夜景；需要全身、半身还是合照？

用户不回答时使用默认值：1 位成年人、他拍、手机 1x、白天、全身、自然抓拍。若用户提供了景点图片，必须以该图为火柴人背景；只有在网上找不到可信的真实景点图且用户未上传图片时，才提示用户“请现场拍一张横向或竖向环境照后继续”。

## 核心工作流

### 1. 场景与图片

- 识别地点、可用背景元素、光线和安全区域。
- 优先检索真实景点图片；图片必须能确认地点或明确标注为该地点。
- 用户上传图优先级最高；网上图片只作参考，不伪装成用户现场视角。
- 图片找不到时停止生成火柴人图，向用户索要现场照片，不用纯色背景或虚构景点替代。

### 2. 每个方案并行生成四项内容

每个方案都必须生成一张火柴人图，不得只在第一个方案生成：

1. 模特站位与姿势。
2. 让模特放松、快速出片、建立信任的摄影者沟通模板。
3. 摄影者机位、构图和参数。
4. 真实景点背景上的火柴人示意图，并配真人参考图（能可靠检索到时）。

### 3. 火柴人图硬约束

- 背景使用用户上传的景点图；无上传图时使用已确认的真实景点检索图。
- 火柴人位置、大小、脚点、朝向、视线、手部和动作必须与文字一致。
- 使用黄/白/橙等高对比填充，配深色粗轮廓、半透明底板或箭头，不能融入背景。
- 图中标注手机位置、人物距离、构图线（如三分线/引导线/框架）和关键动作。
- 人物比例默认全身占画面 70%~85%，头顶和脚下各留 5%~10%。
- 多人图标出站位编号、前中后排或左右分组；儿童和老人用更稳的站姿。

### 4. 方案校验

检查地点、人数、年龄、关系、动作难度、图片真实性、火柴人可辨识度、站位与话术一致性。任一项失败就修正或说明缺失原因，不输出不完整方案。

## 输出模板（每个方案都完整重复）

### 方案 X：名称｜适合谁/情绪

**一、模特站位与姿势**

- 手机与人物距离、人物与背景距离、站位编号/脚点。
- 身体朝向、视线、手部、脚步、表情、触发动作。
- 多人写清前/中/后排或左右分组、间距、谁看镜头/谁看彼此。
- 年龄适配与安全提醒。

**二、摄影者沟通模板**

提供可直接照读的话术，按以下四段组织：

1. **静态摆姿（站定）**：重心、肩膀、下巴、脸部角度、呼吸和视线。
2. **动态抓拍（走动/转身）**：动作速度、手部小动作、连续抓拍提示。
3. **坐姿/靠姿（借力）**：借墙/栏杆的安全方式、腰背、手部和眼神。
4. **细节调整（微调）**：脚尖、手臂留缝、头部、镜头高度和下一张拍法。

话术必须具体、友好、一次只给 1~2 个动作；避免“摆自然一点”等不可执行指令。摄影者应先说明“我会连拍几张，你不用盯着镜头”，拍后可给模特看一张并询问舒适度。

**三、摄影者拍摄卡**

- **机位**：手机落点、高度、方向、距离、镜头焦段/倍率。
- **构图**：从现场选择一种主方法，并用通俗语言说明“怎么找线、怎么放人、为什么这样放”。可选三分线、引导线、框架、对角线、负空间、中心/对称；不要机械套用。
- **参数**：定时、曝光/ISO、连拍、对焦、防抖和光线时段。
- **避坑**：头顶/脚下留白、背景杂物、遮脸、危险边缘、正午顶光。

**四、视觉参考**

- **火柴人示意图**：每个方案必有；给出图片及一句“图中如何读”。
- **真人参考图**：给出网络图片、来源链接、与当前景点/构图的匹配理由；检索不到时明确写“暂无可信真人图”。

## 轻量交互增强（可接入 PoseSnap Mini 思路）

可选地把方案转成“姿势卡”：`id / 场景 / 人数 / 难度 / 全身或半身 / tips / mistakes / joints`。若平台支持相机人体检测，可叠加半透明轮廓并给出 0~100 匹配分数；分数只作为辅助，不阻塞拍照。建议 80 分以上提示“姿势很棒”，50~79 提示一个最大偏差关节，低于 50 给一个调整动作；检测不可用时只显示轮廓和文字。

## 性能与边界

只在用户选择的 2~3 个方案中生成图片；图片检索并行，火柴人生成按方案并行；不下载大图库。用户未提供真实背景且检索不到可信地点图时，必须先索要现场照片。不得把 AI 虚构背景宣称为真实景点。

## 评估指标

图片完整度、火柴人可辨识度、背景真实性、人数/关系匹配度、话术可照读程度、构图可执行度、参数完整度和响应速度。

## 参考来源

构图原则参考 Nikon 人像构图教程（引导线、三分法）、B&H 人像构图入门（三分法、框架构图）和 Sony 人像摄影入门（网格线、框架）。PoseSnap Mini 的姿势卡、轮廓叠加、检测降级和匹配反馈思路来自用户提供的 PRD；用户指定仓库 `https://github.com/chybot/PoseSnap-Mini` 当前无法从网页工具读取，应在接入前人工核对仓库内容与许可证。
