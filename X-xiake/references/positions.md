# 机位库

每个方案都写清手机落点、镜头高度、方向、人物脚点、距离、人物占画面比例、多人排布和留白，并为火柴人图提供同一组数值。

| 场景 | 机位与人物 | 推荐构图 |
|---|---|---|
| 红墙/宫墙 | 手机距人 2.5~4m，胸口高度；人离墙 1~2m，侧身 30~45° | 墙面引导线 + 三分线 |
| 巷口/窄街 | 手机距人 3~5m，平视；人物脚尖朝纵深 | 引导线 + 负空间 |
| 绿树/草坪 | 手机距人 2.5~4m，低于眼睛 10~20cm | 树枝框架 + 三分线 |
| 湖边/水面 | 安全岸线内 2~4m，低机位 | 倒影 + 水平线 |
| 海边/沙滩 | 手机距人 3~6m，平视或逆光 | 地平线三分法 + 负空间 |
| 夜景/灯光 | 稳固支撑点 2~4m，平视或微仰 | 灯带引导线 + 框架 |
| 台阶/高低差 | 下方 3~5m，仰拍 15~25° | 对角线 + 低机位 |

## 通用规则

- 全身人物占画面 70%~85%，头顶和脚下各留 5%~10%。
- 三分法：打开网格，把眼睛或人物主体放在交叉点，视线前方留空间。
- 引导线：寻找道路、墙边、栏杆或灯带，让线条从画面边缘指向人物脸部。
- 框架：用门、树枝、墙体或拱门包住人物，框架不能遮脸。
- 对角线：让台阶、道路或身体线条形成斜线，适合动态和有气场的画面。
- 负空间：在人物视线或行走方向留空，画面会更松弛。
- 多人：按身高分前中后排或左右错位，避免头脸重叠；每个人都要有清楚脚点。
- 先拍一张安全构图，再按同一机位连拍动态版本。
