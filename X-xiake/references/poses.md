# 姿势库

姿势选择顺序：`人数 → 年龄段 → 关系/用途 → 氛围 → 场景`。每个方案必须输出站位、动作和摄影者可照读的话术。

## 沟通模板

### 静态摆姿（站定）

“来，重心放后腿，前腿微弯。肩膀往下沉，不要耸肩，深呼吸放松。身体侧过来一点，双肩错开。下巴往前伸一点点，脸转 45 度，眼神看向远处或镜头上方，不用一直看镜头，保持自然呼吸。”

### 动态抓拍（走动/转身）

“好，慢慢转身回头看向我，动作放缓。手可以轻撩一下头发或搭在衣角，不要僵硬。我会连拍几张，你不用管镜头，保持自己的节奏。”

### 坐姿/靠姿（借力）

“身体轻轻靠在墙上借力，腰背挺直但不要僵硬。手插口袋或轻贴脸颊，不要用力挤压。头微歪，下颌内收，眼神往下看，情绪放松一点。”

### 细节调整（微调）

“双脚前后错开，脚尖朝外。胳膊和身体留点空隙，显手臂细。我换个低角度拍，你身体可以微微前倾靠近镜头一点。”

## 关系与年龄适配

| 类型 | 站位 | 动作 |
|---|---|---|
| 单人成人 | 离背景 1~2m，身体与镜头 30~45° | 回眸、缓步、扶墙、看远处 |
| 儿童 | 靠近陪同者或安全区域 | 挥手、抱腿、看陪同者，不要求跳跃 |
| 老人 | 扶栏或坐姿，脚点稳定 | 看镜头、看家人、轻抬手，不做快速转身 |
| 情侣 | 前后错位或一高一低 | 牵手、并肩走、一人看镜头一人看对方 |
| 家庭 | 成人后排/居中，儿童前排/中间 | 成人看镜头，儿童挥手或抱腿，形成半弧 |
| 朋友 | 弧形或两列，肩膀错开 | 中间主动作，两侧看中心或同步迈步 |
| 公司团建 | 2~3 排阶梯/弧形 | 统一手势，少数人做层次动作，保证全员露脸 |

## 场景动作

| 场景 | 推荐动作 | 构图提示 |
|---|---|---|
| 红墙/宫墙 | 扶墙回眸、沿墙慢走 | 墙面作引导线，人物放三分线 |
| 巷口/窄街 | 缓步、回头、前后错位 | 用巷道纵深和负空间 |
| 绿树/草坪 | 拢头发、抬头、坐草地 | 树枝形成框架，人物避开杂乱背景 |
| 湖边/海边 | 看水、迎风走、背影 | 地平线放上/下三分线，保持安全距离 |
| 夜景/灯光 | 侧身看灯、抬手触光 | 灯带作引导线，脸朝补光方向 |
| 台阶/高低差 | 坐阶、单脚高一级 | 低机位仰拍，脚点完整且远离边缘 |

## 火柴人要求

每个方案单独生成火柴人图，图中必须能读出：人物编号、脚点、朝向、视线、手部、动作箭头、手机距离和使用的构图方法。火柴人必须与背景有明显色差。
