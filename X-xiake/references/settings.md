# 拍摄参数与避坑

| 条件 | 定时 | 参数 | 提示 |
|---|---:|---|---|
| 白天户外 | 10秒 | 1x/2x，ISO 50~200 | 先锁人脸曝光，再入镜 |
| 逆光/日落 | 5~10秒 | 点测人脸，必要时 +0.3~0.7EV | 太阳偏离脸部，避免脸黑 |
| 夜景 | 3~5秒 | 夜景模式，ISO 400~1600，优先 1x | 固定手机，快门后保持不动 |
| 多人/团建 | 10秒+连拍 | 1x，留足横向空间 | 先拍静态，再拍统一手势/走动 |
| 室内 | 5秒 | ISO 400~1600 | 面向窗或柔光，避开顶光 |

## 出片节奏

1. 先拍一张站定测试，确认背景、脚点和脸部曝光。
2. 给模特一条指令，只调整一个部位。
3. 连拍 3~5 张，再让模特看一张，询问是否舒服。
4. 通过后再换动作或机位，避免一次讲太多。

## 必查避坑

- 画面边缘、脚点和头顶留空间；多人不用极端广角硬塞。
- 手机靠墙、栏杆或三脚架时确认稳固；水边、台阶边缘和车道不作为站位。
- 儿童、老人和行动不便者优先稳定站姿或坐姿，不要求跳跃、奔跑、攀爬。
- 避开正午顶光；人脸发黑时改变朝向或补光，不只提高曝光。
- 真人参考图展示时保留来源链接，不声称拥有图片版权。
- 找不到可信真实景点图时，暂停火柴人生成并请用户上传现场照片。
