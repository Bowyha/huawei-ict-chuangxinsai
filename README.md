# X-Xiake · 景点出片教练 Skill

一句话定位：到了景点，发一张现场照、报个地名和几个参数，AI 告诉你"站哪儿、怎么摆、让谁拍、按几下"——把身边任何人（朋友 / 对象 / 路人）临时变成会拍你的人。

## 它做什么

- **输入**：景点名 / 位置 + 参数（拍摄人数、对象关系、风格偏好、社恐等级、当前环境光线与人流量），可选附现场照或拍好的人像照
- **现场指导**：给出最佳机位与推荐焦段、2–3 套姿势方案（站位 / 动作 / 表情 / 手部，含火柴人示意图）、给拍摄者的口语化分步指令、避坑提示
- **出片后处理**：拍完后发照片过来，给出选片建议 + 调色建议 + 朋友圈文案备选

## 它不做什么

不做陌生人约拍撮合、不做修图滤镜（只给调色建议不真改图）、不做社交平台发布、不全程接管摄像头视频流、不替用户按快门。实时视频流引导属于未覆盖的 roadmap（需独立 app + 推理后端）。

## 各文件作用

| 文件 | 作用 |
| --- | --- |
| `SKILL.md` | Skill 的调度中枢：定义何时触发、5 步教练流程（场景识别→姿势生成→拍摄者指令→避坑检测→出片后处理）、边界与停止条件、6 项输入澄清规则、火柴人可视化渲染规则、普通功能降级预案、质量自查清单 |
| `spot-library.md` | 机位知识库：覆盖山岳 / 海滨 / 古镇 / 都市地标 / 园林寺庙 / 网红自然六类共 20 个示范景点；未收录景点走"现场拍图反推可用机位"流程 |
| `pose-library.md` | 姿势知识库：按国风 / 日系 / 胶片 / 大气 / 可爱 × 单人 / 双人 / 群像分类的 17 套详细卡，每套含机位、角度、站位分解、手部动作、表情、肢体动作分步指令、拍摄者分步指令、火柴人 SVG、避坑 |
| `output-format.md` | 统一输出模板与范例：保证现场指导与后期选片 / 调色 / 文案的输出结构稳定、可判定，附西湖断桥完整实例 |
| `coach-flow.md` | 流程细则与避坑：每一步的执行标准、光线 / 背景 / 构图三类避坑清单、给拍摄者的指令生成规则、网络与读图不可用的降级矩阵 |
| `agentarts-migration.md` | 赛题对齐：把本 Skill 的 prompt 流程与知识库映射为华为云 AgentArts 智能体设计方案（多 Agent 拆分、工具编排、知识接入、技能编排、Demo 页面交互、完整闭环） |

## 如何触发

在 WorkBuddy 开一个**新对话**（让 Skill 列表重新加载），说以下任一句即可：

- 在西湖断桥这怎么拍出片
- 我俩他不会拍教教他站哪怎么按
- 社恐不想找路人怎么拍国风的
- 这张拍得行不行帮我选选
- 逆光背景有垃圾桶怎么弄

## 赛题对齐（华为云 AgentArts）

`references/agentarts-migration.md` 把本 Skill 的设计直接映射为华为云 AgentArts 智能体方案：多 Agent 架构（意图识别 Agent / 机位规划 Agent / 姿势编排 Agent / 拍摄者指令 Agent / 后处理 Agent）、工具编排、知识接入（机位库 / 姿势库导入为知识库）、技能编排工作流、Demo 页面交互设计、以及"场景识别→架构设计→技能编排→调试优化→部署上线"的完整闭环。平台实际编排与 Demo 页面代码需在华为云控制台完成，本 Skill 是设计蓝本。

## 未覆盖范围

- 实时视频流引导（需独立 app + 实时多模态推理后端，非 Skill 能力）
- 华为云 AgentArts 平台实际编排部署与 Demo 页面代码实现
- 全国机位库全量覆盖（种子库 20 景点，其余景点走现场反推）
