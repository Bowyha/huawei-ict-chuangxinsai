# 输出格式样例

## 现场回复格式

每条现场回复包含四块：机位焦段、姿势方案、拍摄者指令、避坑提示。

```
📍 当前：[景点名·具体机位]
⏰ 最佳机位：[机位描述，距用户方位]
📷 推荐焦段：[1x全身 / 2x半身 等]

🧍 姿势方案 A（[风格]·[人数]）
  ├─ 站位：[侧身/正身/背影/坐/走]
  ├─ 动作：[手部+身体动作]
  ├─ 表情：[看镜头/看远方/低头/笑]
  ├─ 拍摄者指令："[大白话指令，含距离/高度/时机/张数]"
  └─ 避坑：[该方案具体注意]

🧍 姿势方案 B（...）
  ...

⚠️ 避坑提示：
  - 光线：[逆光/顶光等提醒]
  - 背景：[垃圾桶/人流/割裂线条提醒]
```

## 西湖断桥实例

📍 当前：西湖·断桥残雪
⏰ 最佳机位：桥东侧第三盏路灯旁，侧对桥身（距你约 23 米）
📷 推荐焦段：1x 全身 或 2x 半身

🧍 姿势方案 A（国风·侠客·单人）
  ├─ 站位：侧身对镜头，左脚前右脚后
  ├─ 动作：右手举油纸伞半遮面，左手自然下垂
  ├─ 表情：微抬头看远方，不看镜头
  ├─ 拍摄者指令："你蹲下，手机仰拍 15 度，等风吹动伞沿时按快门，连拍 5 张"
  └─ 避坑：别用广角，会拍成大长腿漫画脸

🧍 姿势方案 B（文艺·背影·单人）
  ├─ 站位：背对镜头，走向桥身
  ├─ 动作：双手自然摆动，步伐放慢
  ├─ 表情：不需表情，背影
  ├─ 拍摄者指令："你站桥这头，手机平举到胸口高度，等她走到第三步时连拍 3 张"
  └─ 避坑：背景别有垃圾桶，移半步避开

⚠️ 避坑提示：
  - 光线：当前逆光，换到顺光侧或给面部补光
  - 背景：桥栏左侧有垃圾桶，站位往右移两步

## 后处理回复格式

拍完发照片后，回复包含三块：选片、调色、文案。

```
📸 选片（从 N 张中挑 X 张）
  第 1 张：[表情好/姿态稳/构图正]，[具体优点]
  第 2 张：...

🎨 调色建议（[风格]）
  - 色温：[偏暖/偏冷]
  - 对比：[高/低]
  - 饱和：[加/减]
  - 一句话方向：[整体调性]

📝 朋友圈文案备选：
  1. "[文案1]"
  2. "[文案2]"
  3. "[文案3]"
```

## 后处理实例

📸 选片（从 5 张中挑 2 张）
  第 2 张：表情自然不僵，侧身弧度刚好，背景垃圾桶已避开
  第 4 张：风吹伞沿的瞬间抓到了，但面部略暗，调色时提亮面部

🎨 调色建议（国风）
  - 色温：偏暖（+300K 左右）
  - 对比：中高
  - 饱和：红绿略加，整体不过艳
  - 一句话方向：往暖调电影感走，保留油纸伞的红

📝 朋友圈文案备选：
  1. "断桥不残，人也不曾老"
  2. "西湖的水，照过霞客也照过我"
  3. "撑一把伞，把断桥走成不残的桥"
