# 华为云 AgentArts 智能体迁移方案

本文件说明如何把 X-Xiake Skill 的 5 步流程迁移到华为云 AgentArts 平台，构建可部署的智能体和 Demo 页面。本 Skill 作为设计方案蓝本，平台编排和部署在 AgentArts 控制台完成。

## 智能体架构

建议拆分多 Agent 协作，每个 Agent 负责一个流程节点：

| Agent | 职责 | 对应 Skill 步骤 |
|---|---|---|
| 场景识别 Agent | 解析景点名，查机位库，返回机位焦段 | Step 1 |
| 姿势生成 Agent | 按人数关系风格抽姿势方案 | Step 2 |
| 拍摄者指令 Agent | 生成口语化指令 | Step 3 |
| 避坑 Agent | 分析光线背景给提醒 | Step 4 |
| 后处理 Agent | 选片调色文案 | Step 5 |
| 编排主 Agent | 接收用户输入，调度上述子 Agent，汇总输出 | 全流程 |

主 Agent 负责对话入口和流程调度，子 Agent 处理专项任务。社恐等级和人数等参数由主 Agent 提取后分发给对应子 Agent。

## 工具编排

每个 Agent 配置对应工具节点：

- 场景识别 Agent：知识库检索节点（查机位库）+ 条件分支节点（命中种子库 / 未命中走现场反推）+ 可选网络检索节点（未命中时查公开机位）。
- 姿势生成 Agent：知识库检索节点（查姿势库）+ LLM 节点（按参数筛选组合方案）。
- 拍摄者指令 Agent：LLM 节点（按规则生成口语化指令）。
- 避坑 Agent：多模态节点（用户发现场照时分析光线背景）+ LLM 节点（给避坑提示）。
- 后处理 Agent：多模态节点（选片，分析照片）+ LLM 节点（调色建议+文案）。

## 知识接入

两个核心知识库导入 AgentArts：

1. 机位库：来自 spot-library.md，结构化为「景点/机位/焦段/黄金时段/注意/适配」字段，按景点分片导入。
2. 姿势库：来自 pose-library.md，结构化为「风格/人数/站位/动作/表情/指令/避坑」字段，按风格×人数分片导入。

导入后在 AgentArts 知识库管理配置检索策略（按景点名/风格/人数等字段精确匹配）。

## 技能编排工作流

把 5 步流程画成 AgentArts 工作流：

1. 用户输入 → 主 Agent 提取 6 项参数。
2. Step 1：场景识别 Agent 查机位库 → 返回机位焦段。
3. Step 2：姿势生成 Agent 查姿势库 → 返回 2-3 套方案。
4. Step 3：拍摄者指令 Agent 给每套方案生成指令。
5. Step 4：避坑 Agent 分析光线背景。
6. 主 Agent 汇总四块输出（机位/姿势/指令/避坑）返回用户。
7. 用户拍完发照片 → 后处理 Agent 执行选片调色文案。

工作流用条件分支处理降级：未发照片时跳过多模态节点，走纯文字路径。

## Demo 页面交互流程设计

可视化 Demo 页面建议的交互流程：

1. 首页：输入框「你在哪个景点？」+ 快捷参数选择（人数/风格/社恐/环境）。
2. 结果页：分四块展示机位焦段、姿势方案卡（可左右切换）、拍摄者指令（可语音播报）、避坑提示。
3. 上传页：用户拍完上传照片，触发后处理。
4. 后处理页：展示选片（带标注）、调色建议、文案备选（可一键复制）。

Demo 页面在 AgentArts 的应用编排或前端页面功能中搭建，调用上述智能体接口。

## 完整闭环对齐

赛题鼓励「场景识别→架构设计→技能编排→调试优化→部署上线」闭环，本方案对应：

- 场景识别：景点出片教练场景，痛点见 SKILL.md 何时使用。
- 架构设计：本文件「智能体架构」多 Agent 拆分。
- 技能编排：本文件「工具编排」和「技能编排工作流」。
- 调试优化：在 AgentArts 用测试对话跑通 5 步流程，调姿势库覆盖和指令质量。
- 部署上线：AgentArts 部署智能体 + 搭建 Demo 页面对外展示。

## 本 Skill 不覆盖的范围

- AgentArts 平台的实际编排操作：在华为云控制台完成，本 Skill 只给设计方案。
- Demo 页面的代码实现：在 AgentArts 应用编排或前端功能中搭建。
- 实时视频流引导：需独立 app + 后端，不在本方案范围。
- 全国景点机位库全量覆盖：种子库仅 8 个示范，未覆盖景点靠现场反推。
