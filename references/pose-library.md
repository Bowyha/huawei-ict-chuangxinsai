# 姿势种子库

按风格 × 人数分类。每张姿势卡含机位、角度、站位分解、手部动作、表情、肢体动作分步指令、拍摄者分步指令、火柴人 SVG 示意图、避坑。用户指定风格直接取对应类；未指定按景点默认风格（见 spot-library 适配项）。

火柴人 SVG 为示意，用于展示肢体动作特征；输出时用可视化工具渲染对应 SVG，并在文字里复述关键动作点。

## 国风

### 国风·单人 A：侠客持伞

- 机位：拍摄者蹲下，侧前方 3 步
- 角度：仰拍 15 度，侧身对镜头
- 站位分解：侧身，左脚前右脚后，重心在后脚，身体微挺
- 手部动作：右手举油纸伞半遮面（伞柄在右手，伞面斜遮右眼上方），左手自然下垂略离身体
- 表情：微抬头看远方，不看镜头
- 肢体动作分步指令：
  1. 侧身站定，左脚迈出半步
  2. 右手举起伞柄，伞面斜遮至右眼上方
  3. 左手自然垂落，手指微张
  4. 下巴微抬，目光投向远方
  5. 定住 3 秒等风吹伞沿
- 拍摄者分步指令：
  1. 蹲下到膝盖高度
  2. 退到侧前方 3 步
  3. 手机仰拍 15 度
  4. 对焦脸部，等伞沿飘动
  5. 连拍 5 张
